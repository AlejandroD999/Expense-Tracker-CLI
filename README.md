# Expense-Tracker-CLI
Expense-Tracker-CLI is a python project that allows users to track their expenses through a command line interface.
The interface is built using argparse with main the main arguments being {add,update,delete,list,summary}. 

# Installation

### Clone repository
```
git clone https://github.com/AlejandroD999/Expense-Tracker-CLI
```

### Use Virtual Environment (recommended)

**Creation**

> Install virtualenv
```
pip install virtualenv
```

> Create
```
virtualenv [name]
```

**Activation**
> Windows
```
[env name]\Scripts\activate.bat
```

> Linux
```
source [env name]/bin/activate
```
